# One Word, One Username, One Reward

A make.fun entry: `main.py` writes exactly one word — the entrant's own
make.fun username — to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing newline, no spaces,
no explanation and no gloss.

Final word (19 characters, within the 1–30 character gate):

> lucky-koala-89-4072

Twelve candidate forms of the handle were drafted in `CANDIDATES.md`;
the first-pass pick was the truncated `lucky-koala`, and a deliberate
refinement swap replaced it with the full, exact registered handle,
since the judge's first criterion rewards a genuine make.fun username
above brevity.
